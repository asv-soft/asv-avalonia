# [icon=CodeBraces;color=Info5;] MarkdownViewer

MarkdownViewer отображает безопасное подмножество Markdown средствами нативных контролов Avalonia. Используйте его для справочных подсказок, встроенной документации, списков изменений и коротких пояснений к статусам — там, где полноценный HTML-Markdown избыточен.

## Основы использования

- Добавьте контрол в XAML и привяжите Text к строковому свойству.
- Держите исходный текст доверенным либо очищайте его перед присваиванием.
- Неподдерживаемую разметку рендерер игнорирует, а не выполняет.

### XAML

<asv:MarkdownViewer Text="{Binding Documentation}" TextWrapping="Wrap" />

## Всплывающие подсказки с Markdown

Используйте MarkdownToolTipConverter, когда подсказка должна отрисовать то же подмножество вместо простого текста.

- Одиночная привязка: ToolTip.Tip="{Binding Description, Converter={x:Static asv:MarkdownToolTipConverter.Instance}}"
- Заголовок вместе с описанием: используйте MultiBinding, где Header идёт первым, а Description вторым.
- ConverterParameter можно задать как статический заголовок для одиночной привязки Description.

## Поддерживаемый блочный синтаксис

- Заголовки: # Заголовок, ## Раздел и ### Подраздел.
- Маркированные списки: - пункт или * пункт.
- Нумерованные списки: 1. пункт, 2. пункт и так далее.
- Обычные абзацы: любая непустая строка, не являющаяся заголовком или пунктом списка.

## Строчные токены

- Токен иконки: \[icon=CheckCircle;color=Success;]
- Токен цвета текста: \[color=Warning;]предупреждающий текст\[/color]
- Полужирный текст: **важный текст**
- Разделитель атрибутов: ставьте точку с запятой после каждой пары «ключ-значение».
- Флаги цвета: комбинируйте значения AsvColorKind через |, например Error|Blink.

## Примеры отрисовки

- [icon=CheckCircle;color=Success;] Успешный пункт с иконкой Material.
- [icon=AlertCircle;color=Warning;] Предупреждающий пункт с AsvColorKind.Warning.
- [icon=Information;color=Info5;] Информационный пункт с Info5.
- Текст может содержать [color=Success;]зелёные фрагменты успеха[/color], [color=Warning;]предупреждающие фрагменты[/color] и [color=Error|Blink;]мигающие фрагменты ошибки[/color].
- Строчное форматирование умеет сочетать [color=Warning;]**полужирные предупреждающие фрагменты**[/color] с обычным текстом.

1. [icon=Cog;color=Info7;] Нумерованный пункт с иконкой.
2. [icon=CodeBraces;color=Info12;] Нумерованный пункт с другим цветом палитры.

## Экранирование

Ставьте обратную косую черту перед открывающей скобкой токена, когда документация должна показать синтаксис, а не отрисовать его.

- Литеральный токен иконки: \[icon=CheckCircle;color=Success;]
- Литеральный цветовой блок: \[color=Success;]текст\[/color]
- Литеральный маркер полужирного: \**не полужирный\**
